# Первый реальный прогон Kuppersberg

Дата: 2026-10-08. Ветки: `server/AIMappingAssistant`, `web3/AIMappingAssistant`.

## Что проверено

Серверные AI-файлы и спецификация присутствуют в рабочей ветке. Восстановление не понадобилось: состояние изменилось после предыдущего осмотра. Прошли 23 серверных теста, TypeScript-проверка, 36 клиентских тестов и production-сборка `web3`. Предупреждения клиентских тестовых заглушек и крупных сборочных файлов не блокируют результат.

Подключение к базе `kuppersberg` успешно. В доступной выборке tenant `default` — 5784 активных атрибута. Поддерживаемые каналы: три Ozon с 50 категориями каждый, два WB с 32 категориями каждый и Яндекс Маркет `ym` (id 21) с 72 категориями. Эти числа относятся к осмотру, а не к постоянному состоянию базы.

Первый тест выбран на `ym`: кухонные комбайны и измельчители, винные шкафы, сковороды-гриль. В каждой категории взяли до пяти существующих прямых соответствий без выражений и до пяти пустых строк, которые присутствуют в актуальном API Яндекс Маркета. Фактически получилось 15 существующих соответствий и одна пустая строка.

Предварительное количество пустых строк в сохранённом маппинге не равно количеству характеристик для AI: часть строк отсутствует в актуальных характеристиках категории. Выборку ограничили актуальными ID и исключили служебные строки, выражения и дубликаты.

## Условия и границы

- БД читалась в транзакциях `READ ONLY`, без инициализации моделей приложения и запуска планировщика каналов.
- Получены актуальные метаданные трёх категорий через API Яндекс Маркета; их описательные поля приведены к формату текущего обработчика канала.
- Использованы `https://ollama.com/v1`, модель `deepseek-v4.1-flash`, формат `json_object`, пакет 5, общий бюджет 300000 мс на вызов сервиса для одной категории.
- Пользователь отдельно подтвердил передачу названий категорий, описаний характеристик и метаданных PIM-кандидатов этому провайдеру после блокировки автоматической проверкой разрешений.
- Ключи маркетплейсов, значения товаров и существующие эталонные соответствия модели не отправлялись.
- Выполнен основной прогон 16 характеристик и повтор первых пяти: всего 21, в пределах подтверждённого теста до 30 характеристик.
- База и сохранённые маппинги не изменены. Таблица применения/отмены на реальных данных через браузер в этом этапе не проверялась.

Время относится к `suggestMappings`, включая последовательные пакеты категории; получение метаданных маркетплейса и чтение БД в него не включены. Пустые результаты: 3. Таймаутов и отказов в этом прогоне не было.

Это **совпадение с существующим маппингом, не измеренная точность**. Сохранённые соответствия ещё не проверены человеком как эталон; другие атрибуты тоже могут быть допустимыми при подходящем источнике значений и преобразовании.

## Где ограничивает shortlist

Из 15 сравнительных строк в пяти прежний атрибут не попал в топ-30. Дополнительное чтение БД подтвердило: все пять атрибутов существуют, входят в видимые группы и применимы к типу 12. Проблема в отборе кандидатов, а не в их отсутствии.

| Характеристика | Существующий PIM-атрибут | Его название в БД |
| --- | --- | --- |
| Тип комбайна/измельчителя | `ymattr_21194330_90601` | Тип (Кухонные комбайны и измельчители) |
| Ёмкость чаши, л | `ymattr_14805551` | Общий объем, л |
| Диаметр верха, см | `ymattr_23681530` | Диаметр, мм |
| Тип сковороды | `ymattr_21194330_61377314` | Тип (Сковороды-гриль) |
| Материал сковороды | `ymattr_17352854_61377314` | Материал (Сковороды-гриль) |

Текущий отбор учитывает название характеристики и группы, но не использует контекст выбранной категории при ранжировании. Общие названия «Тип» и «Материал» конкурируют со множеством атрибутов других категорий. «Ёмкость чаши» и «Общий объем» дополнительно требуют работы с синонимами; различие см/мм — отдельной проверки единиц.

## Где нужен человек

- Для ёмкости чаши предложен `attr_4715` вместо сохранённого `ymattr_14805551`.
- Для диаметра верха предложен `attr_7703` с предупреждением о единицах и необходимости подтверждения назначения.
- Для диаметра дна предложен `attr_6783` вместо `ymattr_36912930`. Даже одинаковое название не подтверждает эквивалентность заполненности источников.
- Для высоты винного шкафа модель выбрала прежний `ymattr_14805336`, но отметила различие мм/см. Поэтому совпадение ID не доказывает правильную передачу значения.
- Для единственной пустой строки «Единиц в одной упаковке» предложен `ymattr_14805583`; числовое соответствие требует проверки.

Все человеческие вердикты в JSON пока `pending`. Эти предложения не сохранены.

## Повторяемость

Повтор категории 90601 занял 19,173 с. Идентификаторы результатов совпали в четырёх из пяти строк. Для «Типа» первый прогон вернул `null`, второй — `attr_4710_17039627_94973`, привязанный к категории «Блендер», с `needsReview = true`.

Один повтор на пяти строках не даёт общей оценки стабильности. Он показывает конкретный риск: при отсутствии подходящего кандидата модель может менять решение между отказом и близким атрибутом чужой категории. Серверная проверка разрешённого ID этого не обнаружит, потому что выбранный ID входит в список кандидатов.

## Решение по следующему этапу

Первым улучшением выбрать ранжирование кандидатов по контексту категории. Проверить, поднимет ли оно категорийные «Тип» и «Материал» в shortlist, не ухудшая остальные результаты. Не увеличивать список без измерений и не подмешивать существующий маппинг в выбор кандидатов: это исказит оценку.

Перед выводами о качестве предметно проверить 15 сохранённых соответствий и одну пустую строку. После улучшения повторить ту же выборку и сравнить отдельно полноту shortlist, совпадение с проверенным эталоном и повторяемость. Дополнительный экспорт данных модели должен соответствовать разрешённому пользователем объёму и составу теста.

Фоновую очередь, embeddings и поддержку MDM пока не добавляли.

## Артефакты и запуск

- [Первый результат с кандидатами и пояснениями](kuppersberg-evaluation.json).
- [Повтор первой категории](kuppersberg-evaluation-repeat.json).
- [Предварительный локальный анализ](kuppersberg-metadata.json): выполнен до приведения названий к точному формату обработчика; не использовать как основную оценку.
- Скрипт: `scripts/ai-mapping/kuppersberg-evaluate.cjs`.

Запуск из `server`:

```powershell
# Только БД и метаданные Яндекс Маркета, без вызова LLM:
node -r ts-node/register/transpile-only scripts/ai-mapping/kuppersberg-evaluate.cjs --metadata-only

# Внешняя передача метаданных согласованному провайдеру:
node -r ts-node/register/transpile-only scripts/ai-mapping/kuppersberg-evaluate.cjs

# Повтор только первой категории:
node -r ts-node/register/transpile-only scripts/ai-mapping/kuppersberg-evaluate.cjs --repeat-first
```

Скрипт предназначен для локального оператора с доступом к серверному окружению. Это диагностический прогон сервиса, а не проверка авторизованной GraphQL-сессии пользователя. Он не запускает обновление каналов или товары. Локальные отчёты перезаписываются при повторном запуске; для сравнения версий их нужно заранее сохранить.
