# Общие поля Яндекса в AI-маппинге

Реализовано 2026-10-09.

Все 27 активных общих полей Яндекса участвуют в массовом подборе, подборе отдельной строки и сравнении существующего маппинга. В UI у них отображается AI-кнопка. `offerid` и `marketCategoryId`, отключённые в текущем редакторе, не добавлены.

Сервер использует доверенный каталог `src/channels/ai/yandexFields.ts`, согласованный с `web3/src/channels/yandex/index.js`. Общие поля доступны только каналу типа 9. Метаданные категории не могут переопределить их типы. Для запроса исключительно общих полей вызов API характеристик категории не требуется. Произвольные поля из сохранённого маппинга не становятся допустимыми целями AI.

Применение:

- `vendor`, `name`, `description`, `vendorCode`: текстовые источники.
- `adult`, `downloadable`, `firstVideoAsCover`: булевы источники.
- `boxCount`: целочисленный источник; дробный требует преобразования.
- `pictures`, `barcodes`, `certificates`, `manufacturerCountries`, `tags`, `videos`: массивы строк; требуется проверка формата.
- Объекты цен, возраста, сроков, состояния, типа товара и габаритов, а также массивы `manuals` и `commodityCodes`: требуется выражение для нужной структуры.

Все предложения для общих полей требуют ручного выбора перед применением. Массивы и объекты показываются в сравнении с пометкой «преобразование» и недоступны для прямого применения пары атрибутов. AI пока не генерирует выражения. Само предложение не подтверждает семантическую корректность выбранного источника.

Существующие значения и выражения сохраняются; применяются только пустые строки после подтверждения. Сохранение канала остаётся явным действием пользователя.

Проверка: 62 серверных теста AI-маппинга с локальным mock HTTP-провайдером, проверка TypeScript, 68 тестов UI/редактора, ESLint и production-сборка. Реальный LLM и экспорт в Яндекс не запускались.
