# Серверный контекст проверки AI-маппинга в WEB

Дата: 2026-10-08. Ветка: `AIMappingAssistant`.

## API

Мутация `suggestChannelAttributeMappings` принимает необязательный `groupIdentifier: String`. Без него используются все доступные группы. Непустой идентификатор должен однозначно соответствовать видимой пользователю группе; неизвестная, скрытая или неоднозначная группа отклоняется. Проверки tenant, прав канала и доступа к атрибутам сохраняются.

Группа ограничивает кандидатов до ранжирования и shortlist; видимость по категории продолжает действовать. Использование общего справочника считается по всем доступным группам.

В `ChannelAIMappingSuggestion` добавлено `review: JSONObject`. Старые запросы без этого поля и аргумента сохраняют совместимость; обновлённому WEB нужна обновлённая схема.

## Review

Review строится сервером из контекста запроса после проверки ответа модели. Типы и единицы не извлекаются из пояснения LLM.

- `kind`: `direct`, `review`, `conversion` или `unmatched`.
- `checks`: предупреждения о типах, единицах, смысловой области и справочниках.
- `marketplace`, `pim`: названия, фактический тип, единица, варианты; у PIM также идентификатор и группа. Без предложения `pim` равен null.
- `candidates`: первые пять кандидатов из shortlist, не дополнительные ответы LLM.

Примеры ограничены восемью строками по 80 символов. Передаются статус загрузки, количество, признак сокращения и число использующих справочник атрибутов. Выход строится по белому списку: конфигурация провайдера, заголовки авторизации и значения товаров не включаются.

Единица маркетплейса берётся из метаданных, единица PIM определяется по ограниченному набору обозначений в названии. Неизвестная единица требует проверки. Смысловые правила пока охватывают размеры изделия/ниши/упаковки и газовые/общие конфорки; это не полноценная семантическая валидация.

Несовместимое представление или единицы отмечаются как преобразование. При одновременном различии смысловой области kind может быть review, поэтому клиент блокирует применение также по checks преобразования. `needsReview` устанавливается для любого результата, отличного от direct. Direct не доказывает точность.

## Применение и проверка

Мутация ничего не сохраняет. WEB может запросить заполненные строки для сравнения, но не заменяет их; текущий маппинг не становится подсказкой LLM. Строки с выражениями не включаются в клиентский запрос. Применяются только неизменённые пустые строки с известным атрибутом и без выявленного преобразования, затем требуется обычное сохранение канала. Выражения и таблицы преобразования вариантов не генерируются.

Прошли 57 целевых серверных тестов и TypeScript-проверка; WEB — 27 тестов, целевой ESLint и production-сборка. Проверены выбор группы, единицы и типы из метаданных, смысловые предупреждения, общие справочники и отсутствие посторонних данных. Браузерная проверка настоящих компонентов выполнена с учебными ответами. Новых экспериментов в БД или модели не проводили.

Инструкция пользователю находится в репозитории `web3`: `docs/ai-mapping/testing-ui.md`.
