## Как открыть

1. Откройте `http://localhost:3000`, войдите как обычно.
2. Конфигурация → «Каналы» → канал **«AI тест — Варочные панели (09.10.2026)»** (id 32, неактивен).
3. Раздел «Категории и маппинг» → выберите категорию в списке сверху (она одна).
4. Опционально: «Искать атрибуты в группе» → «Основные (из 1С)»; по умолчанию — все группы.
5. «Свернуть список каналов» — для максимальной ширины.

### C. Отмена
